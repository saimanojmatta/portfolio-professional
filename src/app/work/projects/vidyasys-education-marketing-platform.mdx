## Overview

Vidyasys is an education and marketing management platform built at DevDolphins. It's an internal client product, so there's no public link — this is a summary of the engineering work rather than a live demo.

## Key Features

- **Hybrid mobile app**: Owned the Marketing PRO app built with React Native (Expo) + WebView, sharing a single web codebase while integrating native capabilities like GPS tracking, biometrics, camera access, and offline functionality.
- **Marketing & Operations features**: Delivered functionality across fee management, contact management, PRO management, dashboards, VMS, IMS, session scheduling, and cohort management.
- **Marketing Suite**: Built a unified React-based admin portal consolidating fee management, contact management, PRO registrations, settlements, and analytics with shared real-time data.
- **Infrastructure management**: Built campus, block, and classroom management features, integrating Google Maps to visualize and manage hierarchical campus structures.

## Technologies Used

React, React Native (Expo), WebView, Google Maps API.

## Outcome

A single hybrid codebase now covers both web and mobile touchpoints for the Marketing and Operations teams, with real-time data shared across the admin portal and field app.
