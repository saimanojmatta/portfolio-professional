## Overview

Traditional portfolio sites felt static, so I built an interactive 3D portfolio using React Three Fiber and Three.js, with animated scenes and smooth camera transitions.

## Key Features

- **Animated 3D scenes**: Built with React Three Fiber and Three.js, with smooth camera transitions between sections.
- **Performance tuning**: Heavy 3D rendering was hurting responsiveness, so I optimized asset loading, rendering, and animations to keep the experience smooth across devices.
- **Reusable components**: Designed reusable UI components and responsive layouts to showcase projects, technical skills, and professional experience.
- **CI/CD**: Deployed on Netlify with a CI/CD workflow for continuous updates.
