## Overview

GetEntrepcare needed a secure, end-to-end payment workflow. It's an internal client product, so there's no public link — this is a summary of the engineering work rather than a live demo.

## Key Features

- **Payment workflow**: Built the end-to-end Instamojo payment workflow, integrating OAuth2 authentication, payment requests, and MongoDB-backed order management.
- **Webhook security**: Secured payment processing by implementing HMAC signature verification on payment webhooks, preventing unauthorized payment status updates.
- **Auth & authorization**: Integrated Auth0 authentication and role-based authorization using JWTs to protect payment APIs and administrative operations.
- **Post-payment automation**: Automated post-payment workflows by syncing purchase data with user profiles and integrating SendGrid for payment confirmation and support emails.

## Technologies Used

Node.js, Express.js, MongoDB, Instamojo API, Auth0, JWT, SendGrid.

## Outcome

Payment status updates are now verified end-to-end via HMAC signatures before they touch order records, closing off a class of webhook-spoofing issues while keeping the post-payment flow (confirmation emails, profile sync) fully automated.
