# Sai Manoj Matta — Portfolio

Personal portfolio site built with Next.js, showcasing frontend engineering work and experience.

## Getting started

**1. Install dependencies**
```
npm install
```

**2. Run dev server**
```
npm run dev
```

**3. Edit content**
```
src/resources/content.tsx
```

**4. Edit site config (routes, theme, SEO domain)**
```
src/resources/once-ui.config.ts
```

**5. Add project case studies**
```
Add a new .mdx file to src/app/work/projects
```

## Before deploying

- [ ] Set `baseURL` in `src/resources/once-ui.config.ts` to the real domain
- [ ] Headshot is `public/images/avatar-manoj.png`
- [ ] Replace `public/images/projects/cover-work.png` with real project screenshots
- [ ] Add the live URL / repo link to the 3D Developer Portfolio project once ready

Built on the [Once UI](https://once-ui.com) design system for Next.js.
